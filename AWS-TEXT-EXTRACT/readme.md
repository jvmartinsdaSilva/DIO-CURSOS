# Amazon Textract

O Amazon Textract é uma ferramenta da AWS que utiliza inteligência artificial para extrair informações de documentos, imagens e arquivos PDF.
O processo básico consiste em enviar o documento para a ferramenta, que analisa seu conteúdo e identifica textos, tabelas, números e outros dados importantes.
Um insight que tive é que essa tecnologia pode reduzir bastante o trabalho manual e tornar processos mais rápidos e organizados.
Também percebi que ela pode ser útil em diferentes áreas que lidam diariamente com muitos documentos.

Ideia 1: utilizar o Textract para extrair automaticamente informações de notas fiscais, como valores, datas e dados dos fornecedores.
Ideia 2: desenvolver um sistema para analisar documentos de cadastro e organizar automaticamente as informações necessárias.
